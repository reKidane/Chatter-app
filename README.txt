HOW TO GO LIVE FROM GITHUB

1. Go to github.com -> New Repository -> name: chatter -> Public
2. Upload these 2 files: index.html + manifest.json
3. Settings > Pages > Branch: main -> Save
4. Wait 1 min -> your live URL: https://YOUR_USERNAME.github.io/chatter/
5. Open on Android Chrome -> Menu -> Install app

TO GET APK:
Go to pwabuilder.com -> paste your live URL -> Package for Stores -> Android -> Download APK -> Upload APK to GitHub Releases
